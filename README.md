## 💻 Featured Projects

### [Linux Driver — BMP180·LCD 드라이버 기반 선풍기 프로젝트](https://github.com/Kevin-jwd/Lectures/tree/main/Linux/%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8)

<img src="https://img.shields.io/badge/C-A8B9CC?style=flat-square&logo=c&logoColor=white" alt="C"> <img src="https://img.shields.io/badge/Linux%20Kernel-333333?style=flat-square" alt="Linux Kernel"> <img src="https://img.shields.io/badge/I2C-0078D4?style=flat-square" alt="I2C"> <img src="https://img.shields.io/badge/Device%20Tree-00897B?style=flat-square" alt="Device Tree"> <img src="https://img.shields.io/badge/Jetson%20Orin%20Nano-76B900?style=flat-square&logo=nvidia&logoColor=white" alt="Jetson Orin Nano"> · 팀 프로젝트

- **담당:** BMP180 온도 센서와 LCD1602A 드라이버, 사용자 공간에서 접근하는 문자 장치 인터페이스를 구현했습니다.
- BMP180의 보정 계수와 변환 완료 상태(SCO)를 확인해 온도를 읽고, LCD는 `pwrite()`로 지정 영역을 갱신하며 `ioctl()`로 화면·백라이트를 제어합니다.
- LCD 백팩의 지원 속도에 맞춰 400kHz 버스에서 100kHz 버스로 분리하고, 배선과 Device Tree 설정을 변경해 LCD 초기화·문자 출력을 확인했습니다.
- 링크에서 담당 범위, 드라이버 구조, 센서 동작과 트러블슈팅 기록을 확인할 수 있습니다.

### [Vehicle HMI — 운전자 인증 기반 차량 제어·모니터링](https://github.com/Kevin-jwd/HMI-qt)

<img src="https://img.shields.io/badge/C%2B%2B17-00599C?style=flat-square&logo=cplusplus&logoColor=white" alt="C++17"> <img src="https://img.shields.io/badge/Qt%20Widgets-41CD52?style=flat-square&logo=qt&logoColor=white" alt="Qt Widgets"> <img src="https://img.shields.io/badge/OpenCV-5C3EE8?style=flat-square&logo=opencv&logoColor=white" alt="OpenCV"> <img src="https://img.shields.io/badge/SQLite-003B57?style=flat-square&logo=sqlite&logoColor=white" alt="SQLite"> <img src="https://img.shields.io/badge/UART-0078D4?style=flat-square" alt="UART">

- C++17·Qt Widgets로 차량 HMI를 구성하고, UART로 STM32의 온습도·거리·주행 데이터를 수신합니다.
- Haar Cascade·LBPH 기반 얼굴 인증을 적용해 미인증 상태의 조작을 제한하고, 5회 연속 동일 인물 확인 후 계기판과 조작 화면을 활성화합니다.
- 카메라 획득·영상 표시·인식을 스레드로 분리하고, SQLite에 시스템·주행·환경·인증 로그를 저장해 기간별로 조회합니다.
- UART 파싱·명령 전송과 200ms 하트비트를 `SerialLink`로 분리하고, DB 접근은 UI 스레드에서 처리하도록 구성했습니다.

### [Vision Tracker — 얼굴 추적 및 UART 전송](https://github.com/Kevin-jwd/Vision_Tracker_Project)

<img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white" alt="Python"> <img src="https://img.shields.io/badge/OpenCV-5C3EE8?style=flat-square&logo=opencv&logoColor=white" alt="OpenCV"> <img src="https://img.shields.io/badge/PyQt-41CD52?style=flat-square&logo=qt&logoColor=white" alt="PyQt"> <img src="https://img.shields.io/badge/UART-0078D4?style=flat-square" alt="UART"> <img src="https://img.shields.io/badge/STM32-03234B?style=flat-square&logo=stmicroelectronics&logoColor=white" alt="STM32">

- YuNet으로 얼굴을 검출하고, 선택한 얼굴의 중심 좌표를 필터링해 팬·틸트 목표 각도를 계산합니다.
- 목표 각도를 체크섬이 포함된 6바이트 UART 패킷으로 전송하고, PyQt 화면에 영상·목표 각도·통신 상태를 표시합니다.
- 현재 가장 큰 얼굴을 추적 대상으로 사용하며, 얼굴 등록과 유사도 비교는 구현 예정입니다.
